# My FTL Syria Program Journey: AI for Climate

Welcome to my learning journal for the Frontier Tech Leaders (FTL) Syria Program – AI for Climate!

This repository documents my progress, key takeaways, and projects throughout this intensive program running from September to December, 2026. FTL program is a unique collaboration between the UNDP, the UNDP Istanbul International Center for Private Sector in Development (ICPSD), and Damascus University, supported by the German Federal Ministry for Economic Cooperation and Development (BMZ) through KfW, in order to build a new generation of tech leaders by connecting technical skills in Progrmming, AI, and Data science to real-world challenges in climate, energy, and environment.
